## [1.0.0] – 2024-04-28

### Added
- Classic Klondike Solitaire layout: 7 tableau columns, 4 foundations, stock & waste piles
- Authentic Windows XP visual styling — blue gradient title bar, menu bar, green felt background
- Standard 52-card deck generation with Fisher-Yates shuffle
- Draw-one card mode from stock pile
- Automatic stock recycling (waste → stock when stock is empty)
- XP-style score tracking with −2 points per card drawn from stock
- Elapsed game timer (seconds)
- Responsive card rendering with face-up / face-down states
- Alternating colour & descending rank display in tableau columns
- In-game **"How to Play"** modal accessible from the Help menu
- README with project description, how to play guide, scoring table, and project structure
- CHANGELOG tracking version history
